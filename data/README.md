## 2. 数据处理

LibriSpeech 音频：

- 封装格式：`.flac`
- 文件扩展名与课程常见输入要求不一致

本项目流水线约定输入为：

- **WAV** 文件
- **单声道**
- **16 kHz**
- **16-bit PCM**
- 统一放在一个扁平目录 `wav/`，便于批量发现与排序

因此，原始 `test-clean` 目录**不能直接作为本仓库默认输入**，主要不合适点如下：

| 不合适点 | 说明 | 处理方式 |
|---|---|---|
| 封装格式多为 FLAC | 项目约定用 `soundfile` 读 WAV | 用 FFmpeg 统一转 WAV |
| 声道/采样格式需显式保证 | 虽来源一般为 16 kHz，但仍需在转换与运行时双重确认 | FFmpeg 指定单声道 + PCM S16LE；程序再校验 |

### 2.1 总体流程

```text
test-clean.tar.gz
    ↓ 解压
LibriSpeech/test-clean/...
    ↓ 随机挑选目录 1089/134686
原始 FLAC（或源音频）38 条
    ↓ FFmpeg 批量转换
\wav\*.wav（单声道 / 16 kHz / 16-bit PCM）
    ↓ 本项目程序校验与特征提取
results/ 与 outputs/
```

### 2.2 FFmpeg 转换目标

转换时统一指定：

- 输出格式：WAV
- 声道：1（mono）
- 采样率：16000 Hz
- 采样格式：16-bit PCM（`pcm_s16le`）
- 文件名：保留 LibriSpeech 原文件名主干，仅把扩展名改为 `.wav`  
  例如：`1089-134686-0000.wav`

典型单文件转换命令示例：

```powershell
ffmpeg -y -i "原始文件.flac" -ac 1 -ar 16000 -sample_fmt s16 "D:\SpeechRecognition\wav\1089-134686-0000.wav"
```

批量转换时可对选定目录下全部源音频循环执行上述参数（关键是 `-ac 1 -ar 16000 -sample_fmt s16`）。

## 3. 数据在本项目中的使用方式

1. **唯一默认输入目录：** `\wav`
2. **发现规则：** 自动扫描全部 `*.wav`，按文件名排序，保证可复现
3. **处理策略：** 每条音频独立跑完 MFCC 流水线，不拼接成长信号
4. **运行时再校验：**  
   采样率是否 16 kHz、是否为空、是否含 NaN/Inf、声道是否被正确处理等  
   （见 `src/preprocessing.py` 的 `load_audio`）
5. **输出隔离：**  
   特征与图表写入 `results/`，课程固定文件名图副本写入 `outputs/`，不回写 `wav/`
